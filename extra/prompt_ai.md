
ให้คุณเข้าไปอ่านไฟล์ในโปรเจ็คที่กำลังอยู่ทั้งหมด โดยเฉพาะ lib/tiny32_v3/  และอ่าน wiring ของวงจรใน #file:diagram.json  เสร็จแล้วแล้วช่วยสรุปเนื้อหาทั้งหมดให้ฉันเข้าใจ



https://github.com/wkoch/Debounce

คุณสามารถนำไลบรารี่นี้มาใช้ใน library tiny32_v3 ของเราเพื่อจัดการกับปัญหา "เด้ง" (bounce) ของการกดปุ่มสวิตช์ SW1 และ SW2 ได้หรือไม่ โดยเข้าไปปรับปรุงฟังก์ชั่น Sw1 และ Sw2 ในไฟล์ lib/tiny32_v3/src/tiny32_v3.cpp โดยใช้ไลบรารี่นี้ช่วยจัดการกับการเด้งของสวิตช์ให้ด้วย


หลังจากทดลอง upload โค้ดที่แก้ไขแล้วขึ้นบอร์ด tiny32_v3 แล้ว และฉันได้ทดสอบการกดปุ่ม SW1 และ SW2 พบว่าเมื่อกดปุ่ม 1 ครั้ง แต่มันกลับทำงาน 2 ครั้ง  ซึ่งแสดงว่าโค้ดยังไม่สามารถจัดการกับปัญหาเด้งของสวิตช์ได้อย่างสมบูรณ์ ช่วยตรวจสอบและแก้ไข

ตอนนี้โค้ดในฟังก์ชั่น Sw1 และ Sw2 ทำงานได้สมบุรณ์แล้ว โดยสามารถจัดการกับปัญหาเด้งของสวิตช์ได้อย่างมีประสิทธิภาพ เมื่อกดปุ่ม SW1 หรือ SW2 จะทำงานเพียงครั้งเดียวตามที่คาดหวังไว้

คุณช่วยปรับปรุง #file:clone_repo.sh  ให้ทำการดาวนโหลดไลบรารี่นี้มาไว้ในโฟลเดอร์ lib/tiny32_v3 แลไลบรารี่นี Debounce ให้ด้วย พร้อมทั้งพิมพ์ข้อความยืนยันเมื่อดาวน์โหลดเสร็จสิ้นได้หรือไม่เป็นภาษาอังกฤษ และสติกเกอร์ น่ารัก ๆ ที่สื่อความหมายด้วย

ช่วยสร้างไฟล์ .bat สำหรับ Windows ที่มีฟังก์ชั่นเดียวกับ #file:clone_repo.sh   โดยให้ไฟล์ .bat นี้สามารถรันได้ใน Command Prompt ของ Windows และดาวน์โหลดไลบรารี่นี้มาไว้ในโฟลเดอร์ lib/tiny32_v3 เช่นเดียวกับสคริปต์เชลล์ และพิมพ์ข้อความยืนยันเมื่อดาวน์โหลดเสร็จสิ้นเป็นภาษาอังกฤษ พร้อมทั้งสติกเกอร์ น่ารัก ๆ ที่สื่อความหมายด้วย

ให้ทำการปรับปรุงไฟล์ README.md ในโฟลเดอรฺ์ lib/tiny32_v3/  โดยเพิ่มข้อมูลของไลบรารี่นี้ Debounce เข้าไปในส่วนของไลบรารี่ที่ติดตั้งไว้แล้ว (Installed Libraries) พร้อมทั้งเพิ่มคำแนะนำในการติดตั้งไลบรารี่นี้แบบแมนนวล (Manual Installation) สำหรับทั้ง macOS/Linux และ Windows ด้วย
